# Muestras visuales del dataset

Seis imágenes de 256 × 256 píxeles, una por clase, tomadas de `val/`. Son referencias para documentación, no se usan para entrenar ni evaluar.

**Atribución:** Shahriar Ahmed Shovo y Samiha Raisa Mostafa, *Processed Tomato Leaf Disease Image Dataset with Train-Validation-Test Split for Deep Learning Applications*, [Mendeley Data, DOI 10.17632/3zwdw6y4pn.1](https://doi.org/10.17632/3zwdw6y4pn.1), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). El dataset es derivado de PlantVillage según la publicación de Mendeley.
